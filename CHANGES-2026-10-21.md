- **Everything, instantly:** go to Shopify admin → Online Store → Themes → "BACKUP before Claude changes 2026-10-21" → **Publish**.
  Or from the CLI: `shopify theme publish --theme 188802629806`.
- **One file only:**
  `shopify theme push --theme 151479124142 --allow-live --nodelete --path "backups/live-theme-2026-10-21" --only <file>`
- **Remove a new file:** files marked NEW below didn't exist before. Delete them in admin → Themes → Edit code.
- **Local code:** `git checkout -- prm-herbovilla-theme/<file>` (all changes are uncommitted).
