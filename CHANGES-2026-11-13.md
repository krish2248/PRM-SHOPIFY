## How to revert (after it goes live)
```
git show ee94c8d:prm-herbovilla-theme/sections/product-template.liquid > sections/product-template.liquid
git show ee94c8d:prm-herbovilla-theme/sections/about-page.liquid > sections/about-page.liquid
git show ee94c8d:prm-herbovilla-theme/templates/product.json > templates/product.json
shopify theme push --theme 151479124142 --allow-live --nodelete --only sections/product-template.liquid --only sections/about-page.liquid --only templates/product.json
```
`snippets/product-video-data.liquid` can stay; the old template doesn't use it.

## How to add videos to a product
- **Krish sends files or links → Claude** adds them to `snippets/product-video-data.liquid` (one `when '<handle>'` line per product).
  Files go to admin → Content → Files first (theme assets are capped at 20 MB); the `.mp4` link from there is what gets used.
- **Or in admin:** Settings → Custom data → Products → add definition `custom.product_videos` (List of single-line text
  or URL), then paste links on each product.
- **Or** upload a video straight into a product's Media; it appears in the photo gallery.
