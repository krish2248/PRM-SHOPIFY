## How to revert
- **One file:** the pre-change version of every file above is identical to git commit `7cdc04e`
  (verified against the live pull). From `prm-herbovilla-theme/`:
  ```
  git show 7cdc04e:prm-herbovilla-theme/<file> > <file>
  shopify theme push --theme 151479124142 --allow-live --nodelete --only <file>
  ```
- **The PDF fix only:** revert `snippets/product-pdf-url.liquid` **and** `sections/product-template.liquid` together
  (the template expects the new list format).
- **Everything since 21 Oct:** publish "BACKUP before Claude changes 2026-10-21" #188802629806 (this also undoes the Oct redesign).
